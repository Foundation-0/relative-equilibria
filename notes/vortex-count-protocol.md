# Five-vortex control protocol

For a regular ring of k unit vortices at radius r, the radial interaction coefficient is (k-1)/(2r squared). Adding a unit central vortex adds 1/(r squared). The generator selects r so that lambda=1. These are known symmetry constructions, not newly discovered configurations.

The finite floating checks test equation conventions only. A full result requires all symmetry classes, compact-domain coverage, interval inclusion, independent verification and a comparison with the source catalogues. A failed Krawczyk test is unresolved; it does not prove a continuous family exists.
